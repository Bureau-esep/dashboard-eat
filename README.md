# Dashboard EAT

Outil de gestion de l'EAT (EIGS'AERO · ESEP) : budget, équipages, logistique, sportif.

- `index.html` : l'application (connexion Supabase intégrée, clé publique).
- `netlify.toml` : réglages Netlify (publication de la racine, en-têtes de sécurité).

Chaque modification poussée sur `main` est publiée automatiquement par Netlify.
